# Metric glossary

Generated by `scripts/build_glossary.py` from the semantic manifest. Do not edit by hand; change the
metric YAML in `models/semantic/` and regenerate.

Query any metric with `mf query --metrics <name> --group-by <dimension> --start-time YYYY-MM-DD --end-time YYYY-MM-DD`.
Every metric can be grouped by `metric_time` (add `__week`, `__month`, ...). Dimensions are listed with
the prefix `mf` needs. Check **Data starts** before asking about an earlier period: an earlier window
returns a partial total, not an error.

## analytics_traffic_days

Analytics API history: views per video per activity day per traffic source, from 2025-10-16.

### `analytics_views`: Views (Analytics API history)

Views from the Analytics API traffic source table, back to 2025-10-16. Within 0.5% of total_views where both exist. Use for periods before 2026-08-06.

- **Type:** simple (sum of measure `analytics_views`)
- **Source:** `daily_traffic_sources`
- **Data starts:** 2025-10-16
- **Group by:** `metric_time`, `analytics_traffic_day__analytics_traffic_source`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

## video_demographic_days

Estimated views by age group and gender per Pacific day and video. Complete from 2026-08-06, but YouTube only reports demographics for videos with enough logged-in viewers (17 to 24 videos a month).

### `estimated_demographic_views`: Estimated Views by Demographic

Estimated views by age group and gender: each row's share of the video-day's logged-in views applied to the video-day's total views. An estimate, and only covers videos YouTube reports demographics for (17 to 24 a month). For a share, divide each group's value by the total of all groups in the same query.

- **Type:** simple (sum of measure `estimated_demographic_views`)
- **Source:** `reporting_channel_demographics_a1`
- **Data starts:** 2026-08-06
- **Group by:** `metric_time`, `video_demographic_day__age_group`, `video_demographic_day__gender`, `video_demographic_day__subscribed_status`, `video_demographic_day__country_code`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

## video_lifetime_snapshots

Lifetime view, like and comment counts per video per snapshot date (Data API), from 2026-02-17. Running totals: they add across videos, and over time the latest snapshot in the period is used.

### `lifetime_comments`: Lifetime Comments

Lifetime comment count at the latest snapshot in the period. Running total.

- **Type:** simple (measure `lifetime_comments` at the latest snapshot in each period, summed across videos)
- **Source:** `daily_video_stats`
- **Data starts:** 2026-02-17
- **Group by:** `metric_time`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

### `lifetime_likes`: Lifetime Likes

Lifetime like count at the latest snapshot in the period. Running total.

- **Type:** simple (measure `lifetime_likes` at the latest snapshot in each period, summed across videos)
- **Source:** `daily_video_stats`
- **Data starts:** 2026-02-17
- **Group by:** `metric_time`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

### `lifetime_views`: Lifetime Views

Lifetime view count from the Data API at the latest snapshot in the period. Running total: compare snapshots, never add across days. Data API timing, not Pacific days.

- **Type:** simple (measure `lifetime_views` at the latest snapshot in each period, summed across videos)
- **Source:** `daily_video_stats`
- **Data starts:** 2026-02-17
- **Group by:** `metric_time`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

## video_reach_days

Thumbnail impressions and clicks per Pacific day, video, traffic source, detail, device and OS (Reporting API reach report). Complete from 2026-08-06. Impressions exist only on six surfaces: YouTube search, suggested videos, browse features, channel page, playlists and playlist pages.

### `impression_clicks`: Impression Clicks

Views that came from a thumbnail impression: impressions times impressions CTR. Additive.

- **Type:** simple (sum of measure `impression_clicks`)
- **Source:** `reporting_channel_reach_combined_a1`
- **Data starts:** 2026-08-06
- **Group by:** `metric_time`, `video_reach_day__traffic_source`, `video_reach_day__traffic_source_detail`, `video_reach_day__device_type`, `video_reach_day__operating_system`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

### `impressions_ctr`: Impressions CTR

Impressions click-through rate as a fraction (0.05 = 5%): impression clicks divided by impressions. Not additive; recomputed from the two totals. Covers only the six impression surfaces.

- **Type:** ratio (impression_clicks / total_impressions)
- **Source:** `reporting_channel_reach_combined_a1`
- **Data starts:** 2026-08-06
- **Group by:** `metric_time`, `video_reach_day__traffic_source`, `video_reach_day__traffic_source_detail`, `video_reach_day__device_type`, `video_reach_day__operating_system`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

### `total_impressions`: Impressions

Thumbnail impressions (Reporting API reach report). Only six surfaces have impressions: YouTube search, suggested videos, browse features, channel page, playlists and playlist pages. No Shorts feed, external or direct traffic, so never divide views by impressions. Additive.

- **Type:** simple (sum of measure `impressions`)
- **Source:** `reporting_channel_reach_combined_a1`
- **Data starts:** 2026-08-06
- **Group by:** `metric_time`, `video_reach_day__traffic_source`, `video_reach_day__traffic_source_detail`, `video_reach_day__device_type`, `video_reach_day__operating_system`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

## video_traffic_days

Views, engaged views and watch time per Pacific day, video, subscribed status, country, traffic source, device, OS and playback location (Reporting API combined report). Complete from 2026-08-06.

### `avg_view_duration_seconds`: Average View Duration (seconds)

Average view duration in seconds: total seconds watched divided by engaged views, which is how YouTube computes it. Not additive; always recompute from the two totals.

- **Type:** ratio (total_seconds_watched / total_engaged_views)
- **Source:** `reporting_channel_combined_a3`
- **Data starts:** 2026-08-06
- **Group by:** `metric_time`, `video_traffic_day__attribution`, `video_traffic_day__subscribed_status`, `video_traffic_day__country_code`, `video_traffic_day__traffic_source`, `video_traffic_day__device_type`, `video_traffic_day__operating_system`, `video_traffic_day__playback_location`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`

### `total_engaged_views`: Engaged Views

Engaged views (Reporting API): views past YouTube's engagement threshold. Average view duration is computed over these. Additive.

- **Type:** simple (sum of measure `engaged_views`)
- **Source:** `reporting_channel_combined_a3`

- **Group by:** `metric_time`, `video_traffic_day__attribution`, `video_traffic_day__subscribed_status`, `video_traffic_day__country_code`, `video_traffic_day__traffic_source`, `video_traffic_day__device_type`, `video_traffic_day__operating_system`, `video_traffic_day__playback_location`, `video`, `video__title`, `video__video_type`, `video__published_date`, `video__duration_seconds`
